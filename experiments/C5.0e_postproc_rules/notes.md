# C5.0e 后处理上界诊断（零重训的两条规则）

## 目的

Oracle 实验证明"实例归属"值 **+0.079 TRA**（0.9057 → 0.9848）。本实验回答一个
更便宜的问题：**不重训任何模型，只靠后处理规则能吃掉其中多少？**

为避免"手工拟合数据集"，两条规则各只有**一个相对量参数**，不含任何绝对体素常数；
并按约定：seq01 定参数、seq02 验证（真实检测档的 seq02 尚未生成，留待后续）。
两条规则全部标注为**论文之外的工程补充**，主链路默认配置不变。

## 规则 B：孤立短轨迹过滤（结果：净负，不采纳）

**动机**：论文 §2.0.1 声称"假阳性节点难以与前后帧形成平滑路径 → 会被孤立"。
本规则把这个断言变成可评测的操作：删除"长度 ≤ L 且既无父也无子"的轨迹。

| 配置 | 轨迹数 | FN | FP | IDsw | 碎片 | 分裂 P / R |
| --- | --- | --- | --- | --- | --- | --- |
| 基准（无过滤） | 4864 | **87** | **2456** | 3832 | 3479 | 0.489 / 0.874 |
| L=1（只删单帧孤立） | 2445 | 1037 | 910 | 3755 | 2530 | 0.455 / 0.615 |
| L=2 | 2055 | **1769** | **763** | 3613 | 2097 | 0.450 / 0.508 |

**判读（按 AOGM 权重 FN=10 / FP=1）**：

| | FP 改善 | FN 增加 | AOGM 净变化 |
| --- | --- | --- | --- |
| L=1 | −1546 | +950 | **+7954（更差）** |
| L=2 | −1693 | +1682 | **+15127（更差）** |

→ **规则 B 是负结果**：删掉的"孤立短轨迹"里含大量真实目标（序列边界、
分裂前后的短暂出现、以及被实例化错误打断的真轨迹）。**论文 §2.0.1 的
"孤立即假阳性"假设在本数据上不成立**，假阳性抑制不能靠长度/孤立性规则，
必须由学习承担（与 Oracle 的结论一致：问题在实例归属，不在后处理规则）。

## 规则 A：超大实例再切（本地完成，官方指标待开机）

**做法**：体积 > `k × 同帧实例体积中位数` 的实例，用 `0.5 × h_frac` 在其
**包围盒内**重新找种子并做分水岭；切不动（仍只有 1 个峰）就保持原样。
参数只有一个相对量 `k`（本轮取 1.6）。

> 工程记录：初版对**整卷**做距离变换（35×512×708 float64 ≈ 100MB/次），
> 15 分钟只跑完约 1/5 帧且进程中途死亡；改为**包围盒裁剪**后，密集帧的再切
> 从 ~9s 降到 **2.1s**，全量 195 帧约 34 分钟完成。

| 指标 | v2 基准 | **再切 k=1.6** |
| --- | --- | --- |
| 实例/帧 | 122.9 | 130.7（GT 122.1，即 **+7% 过分割**） |
| 检测召回 / 精确 | 0.996 / 0.903 | 0.996 / 0.895 |
| GNN move F1 / div F1 | 0.8907 / 0.2150 | **0.9046** / 0.2116 |
| 本地轨迹数 | 4864 | 5616 |
| 本地 FN | **87** | 113 |
| 本地 FP | **2456** | 3067（变差） |
| **本地 ID switch** | 3832 | **2225（−42%）** |
| 本地碎片化 | 3479 | 3482（持平） |
| 本地分裂 P / R | 0.489 / 0.874 | 0.442 / **0.911** |

**判读**：这正是"该由官方指标裁决"的典型局面——
- 变好的一侧：ID switch −42%、分裂召回 +3.7pt、GNN move F1 +0.014，
  说明切开了原本"一个节点顶两条轨迹"的情况（对应 AOGM 的 **NS** 项，官方口径下才是关键）；
- 变差的一侧：FP 增加 611（本地口径），因为多切出来的实例里有一部分是假阳性。

按 AOGM 权重粗算：FP +611×1 = +611，FN +26×10 = +260，合计约 **+871 更差**；
但 **NS 减少 5 倍权重**（每减少一次多余分裂操作省 5），本地指标看不到这一项，
而 Oracle 实验显示 NS 是占比 43% 的大项（2199 → 211）——因此**必须看官方 AOGM 分解**。

## 汇总：两条规则的定位

| 规则 | 参数 | 本地结论 | 用途 |
| --- | --- | --- | --- |
| A 超大实例再切 | k=1.6（中位数倍数） | 混合（IDsw 大降、FP 升） | 待官方裁决；若 NS 明显下降则保留为工程补充 |
| B 孤立短轨迹过滤 | L=1/2（帧） | **净负**（FN 权重 10×） | **不采纳**；作为"孤立即假阳性"假设不成立的证据 |

两条规则都满足"单一相对参数 + 不含绝对体素常数"的约束；seq02 验证待 seq02
真实检测档生成后进行。
