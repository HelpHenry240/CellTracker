# C4A 全链路官方评测：OT + GNN（论文口径，cand_topk=3）

## 目的

给"三档检测来源"里的**真实检测档**补上第一个官方数字：nnU-Net 预测实例（C5.0 修复后的 v2
检测）+ 论文口径 pipeline（式(26) 候选 + GNN 决策 + 式(35) 正则）端到端的
DET / SEG / TRA，并用 AOGM 六项分解做误差归属。

## 配置

| 项 | 值 |
| --- | --- |
| 检测来源 | `data/interim/Fluo-N3DH-CE_01_pred_v2.h5`（实例/标记 1.007） |
| 训练/测试同源 | 是：GNN 在 `graphs_01_pred_v2b`（同一预测检测 + GT 血缘）上独立重训 60 epoch |
| 权重 | `experiments/C5.0b_pred_v2_train/artifacts/model/best.pt` |
| 决策 | GNN 边分类（无自创融合） |
| 候选 | 式(26) `θ_Γ=0.02` + 工程补充 top-k=3 |
| 其他 | η=0（无 FGW）、τ=None（平衡 OT）、运动先验 0、多尺度关、tracklet 关 |
| 评测 | 云端官方二进制（`--official`），临时目录已自动清理 |

## 结论

1. **真实检测档的端到端基线落定：TRA 0.9057**（对比 GT 检测上界 0.996513）。
   这个差距就是"前端检测不完美"的代价——检测层天花板：节点检出 0.905、移动边可达 0.846、
   分裂可见 0.723。
2. **误差主要来自三处**（按加权成本）：缺失边 EA 11403、多余分裂操作 NS 10995、
   假阳性节点 FP 2456。三者合计占 AOGM 的 96%。
   - FP 2456 ≈ 12.6 个/帧（检测集里约 10% 是多余的实例）→ 需要 GNN/重建层抑制，
     正是论文 §2.0.1 声称的能力；
   - NS 2199 远超真实分裂数（358）→ 过分割被官方指标计为"多余分裂操作"，
     这是 Distance Head 这类**前端实例化**改进的潜在靶点。
3. 与 D（匈牙利基线，同一检测）的对比**尚未做**——这是"方法在真实检测上是否仍有价值"
   的关键问题（本轮按用户要求只跑 A/B）。
