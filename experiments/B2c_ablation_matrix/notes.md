# B2 消融矩阵（完整表）—— CE seq01，CTC 官方指标

## 方法

对每一项消融独立执行「用消融后的配置重建图 → 重训 GNN → 官方评测」。
**必须重训**：本 pipeline 里几乎每个模块都会改变 GNN 的输入分布
（候选边集合或边特征），沿用原模型测到的是"分布漂移"而非模块贡献。

**噪声地板 = 0.0007**（两次等价配置的 TRA 差，见 `experiments/B2_methodology/`），
因此本表按与噪声地板的比值判定显著性。

## 结论

### 1. 学习型决策是最大贡献项（ΔTRA −0.0034，4.9× 噪声地板）

关掉 GNN、回退到手工 OT 规则后 TRA 掉到 0.993135。且手工规则**找不到好工作点**：
`div_ratio=0.3` 时过分裂（1610 轨迹）、`≥0.5` 时完全测不出分裂（388 轨迹）。
这与 A2 的"手工阈值与 ε 强耦合"结论一致。

### 2. 式(26) 的 OT 候选筛选与 top-k 保底确实有用（各约 −0.0011~−0.0012）

关掉后轨迹数从 755 涨到 1100~1300、碎片化涨到 440~570。
这正是论文 §2.0.1 的核心机制。

### 3. 论文的三个"扩展"在本数据集上都**没有正收益**

| 扩展 | ΔTRA | 与 A2 先验判别力测量是否一致 |
| --- | --- | --- |
| FGW 结构项（η=0.3） | −0.0009 | ✅ 一致（AUC 0.9931→0.9870） |
| 非平衡 OT（τ=1.0） | −0.0023 | ✅ 一致（AUC 0.9931→0.9873） |
| 运动先验（α′=1.0） | −0.0009 | — |

两条独立证据（先验判别力 AUC + 端到端官方 TRA）指向同一结论：**在 CTC CE
的 marker 检测设定下，朴素的平衡熵正则 OT 已经是更好的先验**。

**重要限制**：每项只测了**一个参数值**（η=0.3 / τ=1.0 / α′=1.0）。
更温和的取值（如 η=0.05、τ=10）可能不伤性能。要下"该扩展无益"的结论，
必须先做参数扫描——这是 Phase B 的待办（见下）。

### 4. 第二层 tracklet OT 的收益在噪声内，但显著改善碎片化

TRA +0.0001（噪声内），但**碎片化 174 → 79（腰斩）**，同时 IDsw 139 → 266。
碎片化对 AOGM 的贡献是 ED/EA（1.0–1.5），身份跳变是 EC（1.0），两者代价接近，
所以净效果很小。**要兑现论文的遮挡恢复收益，必须先做空洞补检测（Phase C）。**

## Phase B 待办（按优先级）

1. **参数扫描**：η ∈ {0.05,0.1,0.3}、τ ∈ {1,5,20}、α′ ∈ {0.2,0.5,1}，
   确认"扩展无益"是参数问题还是机制问题；
2. **多随机种子**：对关键结论（式26、top-k、GNN）跑 3 个种子取均值±标准差；
3. **seq02 复验**：目前所有结论仅基于 seq01；
4. **多尺度**：待其下降效率问题修复后再测（当前性能不可接受）。
