# E4.1 动态图 GNN 训练（CE seq01）

## 目的

验证 ideas.pdf §2.0.1 的核心主张：以 OT 候选边为输入、用图神经网络学习
"该连 / 该分"，从而纠正仅基于两帧的 OT 局部最优。

## 图构造（`src/celltracker/graph/build.py`）

- **节点** = 两帧的检测：归一化坐标(3) + log 体积(1) + 强度均值/标准差(2) + 归一化时间(1)
- **跨帧候选边** = `‖Δx‖ ≤ R_max` 的全部配对，边特征 10 维：
  位移(3)、位移模长、尺寸比、OT 成本、运动先验残差、OT 传输质量、
  行归一化质量、**是否为行内 argmax**
- **帧内边** = kNN(4) 邻接（提供局部拓扑上下文）
- **标签（3 分类）**：0=无关联 / 1=同一细胞继续 / 2=分裂

CE seq01 图数据集：**194 对帧、94,003 条候选边**，标签分布
`none=70,324 (74.8%) / move=23,075 (24.6%) / division=604 (0.64%)`
—— 分裂边极度稀有，是任务的主要难点。

## 模型（`src/celltracker/gnn/model.py`）

每层"边更新 → 节点更新"交替消息传递（式 30–32），3 层、隐藏 64：

```
e'_{u→v} = φ_e(e_{u→v}, h_u, h_v)      # 边特征 + 两端节点特征
m_v      = Σ_{u→v} e'_{u→v}             # 聚合
h'_v     = φ_h(h_v, m_v)                # 节点更新
```

3 分类边头（式 33）+ 类别加权交叉熵（式 34）+ OT 成本一致性正则（式 35）。

## 观察

- "移动边"几乎被完全解决（F1 0.993）—— 说明 OT 代价 + 邻域上下文足以判定
  常规的帧间对应。
- **分裂 F1 峰值 0.6215**，远高于手工判据的精确率 0.446；但波动较大
  （分裂样本只占 0.64%），best checkpoint 按 move+div F1 选择。
- 训练曲线见 `figures/training_history.png`。

## 结论

图模型确实学到了"何时该分"的可辨识模式 —— 这正是手工阈值做不到的部分。
