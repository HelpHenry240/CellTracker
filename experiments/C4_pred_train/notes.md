# C4b 在预测检测图上重训 GNN

## 目的

按 R11（训练与测试检测来源同分布）在 `graphs_01_pred`（预测检测）上独立重训 GNN，
作为全链路评测的决策模块；与 B1 的 GT 检测版 GNN 构成"检测来源"这一自变量的对照。

## 做了什么

```bash
python scripts/run_gnn.py train --graphs data/interim/graphs_01_pred \
    --exp-id C4_pred_train --epochs 60
```

损失与结构完全沿用论文口径（式(34) 边分类 CE + 式(35) `L_OT-reg`），未做任何改动。

## 观察

| 指标 | GT 检测图（B1） | **预测检测图（C4b）** |
| --- | --- | --- |
| 训练耗时 | 87.8 s | **48.7 s**（候选边更少） |
| 最优 move F1 | 0.9916 | **0.7480** |
| 最优 division F1 | 0.5207 | **0.3841** |
| 语义准确率（移动 vs 分裂） | 0.9832 | 0.9550 |

## 结论

同一模型、同一损失、同一训练轮数，仅换检测来源，move F1 从 0.99 掉到 0.75。
**这不是模型问题，是标签质量问题**：`gt_label` 是"重叠最大的 GT id"胜者通吃，
而同一个真实细胞在相邻帧常被不同实例代表（C4a 的 U2 仅 13.7%），
于是"同一轨迹 = 移动边"的监督在时间上不连续。
→ 再次指向同一结论：前端实例质量决定学习质量。

## ⚠️ 事后更正（2026-09-20，C5.0b）

本实验用的图数据集 `graphs_01_pred` 存在**分裂标签污染**：
预测 h5 没有 `tracks` 表 → `gt_parent` 为空 → 标签规则
`gt_parent.get(gl_d, 0) == gl_s` 在源检测是假阳性（`gl_s = 0`）时退化成 `0 == 0`，
把所有假阳性源边标成了分裂（5866 条 vs 真实 453 条），假阳性↔假阳性边被标成移动。

因此本目录报告的 move/div F1（0.748 / 0.384）是在污染标签上的读数，
**不能作为"分裂头学不会"的证据**。修复见 `experiments/C5.0b_label_fix/`：
修复后同一检测下分裂事件 S3 从 2.2% 升到 21.1%、本地分裂精确率 0.011 → 0.489。
