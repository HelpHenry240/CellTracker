# C5.0c 候选规则变体（分裂事件覆盖）

## 目的

C5.0b 之后误差漏斗显示：**分裂事件在候选生成阶段（S1）就只剩 48.2%**，
是当前最大的单点损失。本实验在**不改动论文机制**的前提下，扫描两个已有参数：
式(26) 的阈值 `theta_gamma` 与工程保底 `cand_topk`（论文之外的补充，见 AGENTS.md 口径约定）。

## 结果一：事件级候选覆盖（369 次真实分裂，不带 GNN）

| 变体 | S1 两个子目标都在候选集 |
| --- | --- |
| base（topk=3, θ_Γ=0.02） | 178（48.2%） |
| **topk=5** | **288（78.0%）** |
| θ_Γ=0.005 | 192（52.0%） |
| topk=5 + θ_Γ=0.005 | 289（78.3%） |

**`cand_topk` 是主杠杆**（+29.8 个百分点），`theta_gamma` 几乎无影响（+3.8）。

## 结果二：topk=5 + GNN 的完整漏斗与本地指标

| 阶段 | base（C5.0b） | topk=5 |
| --- | --- | --- |
| move 边 S3 留存 | 83.1% | **84.4%** |
| 分裂边 S3 留存 | 41.7% | **45.0%** |
| 分裂事件 S1 | 48.2% | **78.0%** |
| 分裂事件 S2 | 29.3% | **35.0%** |
| 分裂事件 S3 | 21.1% | **23.8%** |
| 本地轨迹数 | 4864 | **4304** |
| 本地碎片化 | 3479 | **3021** |
| 本地 ID switch | 3832 | 3971（略差） |
| 本地分裂 P / R | 0.489 / 0.874 | 0.508 / 0.852（互有胜负） |

## 结论与状态

1. **候选覆盖确实可以靠 `cand_topk` 大幅改善**（48% → 78%），且不违反论文口径
   （top-k 本就是标注过的工程补充）。
2. 但端到端收益被**下一级卡住**：S1 78% → S2 35%，即"两个子目标同时进入 top-2"
   仍然丢一半。说明**决策阶段的分裂选择**（不是候选）是下一步的真正瓶颈。
3. 本地指标**互有胜负**（碎片/轨迹数变好，IDsw/分裂召回略差），
   按 R4 不能据此改默认参数——**状态：待官方指标裁决**（云服务器可用后跑 A/B）。

## 下一步

1. 云可用后：v2b 的 base 与 topk=5 各跑一次官方 TRA（同一检测、同一训练流程）；
2. 决策阶段的 top-2 选择问题（S2）优先于继续扩大候选；
3. 若确认 topk=5 更优，则把 `cand_topk` 默认值改动记为一次显式的参数变更
   （论文口径 + 工程补充分别说明）。
