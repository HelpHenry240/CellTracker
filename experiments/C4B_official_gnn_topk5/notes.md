# C4B 全链路官方评测：OT + GNN（cand_topk=5）

## 目的

裁决 C5.0c 的悬案：把工程补充 `cand_topk` 从 3 提到 5，能把分裂事件的候选覆盖
从 48.2% 提到 78.0%，但**本地端到端指标互有胜负**（碎片变好、IDsw 变差），
按 R4 必须由官方指标裁决。

## 配置

与 C4A 完全相同，唯一差异是 `graph.cand_topk=5`（权重为同配置下独立重训的
`experiments/C5.0c_topk5_train/artifacts/model/best.pt`）。

## 结果（CTC 官方指标，seq01 195 帧）

| DET | 0.939833 | 0.939833 | 0（同一份检测） |
| SEG | 0.673196 | 0.673196 | 0（同一份检测） |
| **TRA** | 0.905706 | **0.906542** | **+0.000836** |

## 结论

1. B 的收益机制与预期一致：**缺失边 EA 减少 154 条**（−231 加权成本），
   ED 减少 6；代价是 EC（语义错误）增加 8。净 AOGM −229 → **TRA +0.00084**。
2. **但 +0.00084 与噪声地板 0.0007 同量级（1.2×）**：按 R10，这个差值
   "几乎不能与噪声区分"，**不足以支撑把默认参数从 3 改成 5**。
   谨慎表述应为"方向一致、幅度在噪声边缘"。
3. 要把它变成可写进论文的结论，需要**多种子复验**（≥2 个训练种子，
   每种子各跑 A/B），这也符合 R9 对关键结论的要求。
4. 本地指标的判断（碎片 3479→3021 更好、IDsw 3832→3971 更差）在官方 TRA 上
   表现为轻微正收益——再次印证"本地指标只能判方向、不能定论"（R4）。
