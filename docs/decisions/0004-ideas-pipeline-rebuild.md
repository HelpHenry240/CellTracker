## 数据与阶段契约

1. 检测 H5 保存预测实例、物理间距、完整 GT 标记重叠映射和检测来源；逐帧处理体数据。
2. 外观特征来自已训练 nnU-Net 的冻结 encoder，保存检测 label、帧号、模型指纹与预处理信息；强度统计保留为显式消融。
3. PairCoupling 保存不可变的原始 C、质量和距离；优化只更新 Γ。FGW 和多尺度线搜索都评价完整目标。
4. 时间图包含窗口内每对相邻帧的候选边及可选桥接边，训练标签只作用于目标边；帧内边提供物理空间与外观差异。
5. GNN 模型与图数据记录特征 schema、上游配置和检测来源指纹；按时间块分割并排除重叠上下文。
6. 重建统一处理边阈值、冲突、体积守恒分裂、生死、孤立节点和不确定区域；每类机制有独立开关和统计。
7. 局部高置信关联在滑动窗口中形成 tracklet；二层使用物理端点、平均速度与体积摘要。父子关系指向父终末片段。
8. 原始轨迹保留空洞；CTC 导出明确记录补画或拆段策略，官方入口强制格式校验，失败必须非零退出。

## 论文口径

- 式(18)/(19) 默认使用原始质量 Γ 的字面乘积。条件概率复合作为显式工程对照，使用完整归一化 Jacobian。
- 式(24)/(26) 默认采用经数据标定的绝对 Γ 阈值；源质量比例方式保留为工程对照。
- §1.6 生死默认执行绝对行/列质量阈值，另保留相对阈值和诊断模式用于对照。
- 式(6) 使用原文 sigma²；FGW 使用 D，完整/局部截断方式均明确命名。
- §2.0.1 分割错误处理按文字落实为：边抑制后的孤立节点排除、冲突选择代表节点、异常多源/多汇区域登记及有限父子筛选。阈值和冲突排序属工程离散化，不增设学习损失。
- 滑窗与二层 OT 的原文未规定细节：用窗口内高置信前向边的无冲突连通链作为片段，用原有位置/速度/尺寸代价组成粗层代价，明确记录参数和候选损失。

配置集中管理各阶段，消融注册表按基准状态反向切换模块。每个学习相关变体独立建图、训练、评测；模型不跨配置复用。提供模块清单、有效配置导出、执行时间、接受/拒绝计数和恢复状态。

顺序：解析/梯度回归 → 全模块接口与开关测试 → 小样本全链路 → 云端两序列建图与 GNN 训练/推理 → 官方 DET/SEG/TRA → 根据漏斗定位瓶颈 → 必要的整体配置消融和多种子复验。新设置以重复运行重测噪声地板；不直接沿用历史显著性判断。
