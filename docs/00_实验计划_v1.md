## 1. 研究目标与核心假设

方法骨架（来自 ideas.pdf）：

```
图像 → (nnU-Net 分割) → 每帧检测 {质心 x, 尺寸 s, 表观特征 f}
     → 每帧测度 μᵗ + 帧内 kNN 图 Gᵗ
     → 相邻帧 (非平衡) OT：C_feat(位置/尺寸/运动先验) + η·FGW 结构项 + ε·熵 + τ·KL
     → 多尺度时间一致性 R_temp^(k) (k=2,3,5) + tracklet 二层 OT
     → 时间展开图 (节点=细胞实例, 边=OT 候选关联)
     → GNN 边级二分类 → 残差校正 OT 决策
     → 轨迹重构(最大化 Γ + 阈值筛 + 生死/分裂判定) → 谱系图
```

待验证假设：

| 编号 | 假设 | 验证手段 |
| --- | --- | --- |
| H1 | 帧内结构项（FGW, η>0）在密集同质场景下优于纯特征 OT（η=0） | η 扫描消融，TRA/DET 对比 |
| H2 | 非平衡 OT（KL 松弛）比硬边缘约束更好地处理出生/死亡/分裂 | 平衡 vs 非平衡对比 + 事件级统计 |
| H3 | 多尺度时间一致性 + 运动先验抑制长程轨迹漂移 | 随时间的 ID-switch / 轨迹断裂曲线 |
| H4 | 时间展开图上的 GNN 残差校正优于纯 OT 后处理 | 有无 GNN 的配对对比，误差归因表 |
| H5 | 轨迹级建模对分割误差（FN/FP/过分割/欠分割）具备鲁棒性（§2.0.1 论断） | 合成退化注入实验 + 真实 nnU-Net 误差链 |
| H6 | 整体框架在时间/内存上可接受（每帧 10²–10³ 细胞） | 运行时与显存/内存 scaling 曲线 |

## 2. 数据集与评估协议（CTC）

### 2.1 数据集选择（**3D 为主**，v2 修订）

| 批次 | 数据集 | 模态/维度 | 规模（以 E0.2 实测为准） | 选择理由 |
| --- | --- | --- | --- | --- |
| **主力** | **Fluo-N3DH-CE** | 3D 荧光（C. elegans 胚胎） | 2 seq（01: 35 帧 / 02: 190 帧），512×708×35 | 高密度、分裂频繁、谱系明确（可评 CCL），最贴合文档"高密度+分裂+谱系"难点 |
| 第 2 | **Fluo-N3DH-CHO** | 3D 荧光（CHO 细胞） | 2 seq × 92 帧，512×512×21 | 细胞大而稀疏，检验非平衡 OT 的出生/死亡建模 |
| 第 3 | **Fluo-N3DL-DRO** | 3D 荧光（果蝇胚胎） | 2 seq，体数据量大 | 最大尺度 3D 验证，考验效率（云上做） |
| 快速代理 | Fluo-N2DL-HeLa | 2D 荧光 | 2 seq × 92 帧，~1100×700 | 高密度 2D，CPU 秒级迭代，用于超参与消融的代理搜索，结论再回 3D 复验 |

评测协议：

- 主力 3D 数据集用训练序列 `01` 训练 / `02` 测试，并做 leave-one-sequence-out 双向报告；每个序列单独出指标 + 平均，禁止只报平均。
- 3D 的 SEG 只在 `_GT/SEG` 稀疏参考帧上计算，DET/TRA 在 `_GT/TRA` 稠密标注上计算。
- 3D 提交格式：每帧一个多页 TIFF 栈（`mask000.tif`…）+ `res_track.txt`。

### 2.2 数据格式（内部约定）

CTC 原始结构（2D 示例）：

```
Fluo-N2DL-HeLa/01/          t000.tif ...            # 原始图像
Fluo-N2DL-HeLa/01_GT/SEG/   man_seg000.tif ...      # 稀疏帧的全像素 GT（SEG 打分用）
Fluo-N2DL-HeLa/01_GT/TRA/   man_track000.tif, man_track.txt   # 稠密追踪 GT
```

`man_track.txt` / `res_track.txt` 每行：`L B E P`（标签、起始帧、结束帧、父标签，`0` 表示无父）。
提交结果命名：`mask000.tif ...` + `res_track.txt`（3D 时每帧为多页 TIFF 栈）。

内部统一中间表示：每序列一个 `dataset.h5`（每帧：labels 的 run-length 或稀疏索引、质心、面积/体积、帧号、GT lineage 映射），避免反复解析 TIFF。

### 2.3 指标（用官方二进制，不自己实现）

| 指标 | 含义 | 关键点 |
| --- | --- | --- |
| SEG | 平均 Jaccard | 仅在 `_GT/SEG` 参考帧上计算；GT 目标需被 >50% 覆盖才配对，未匹配记 0 |
| DET | 检测 AOGM 归一化 | `1 - min(AOGM_D, AOGM0_D)/AOGM0_D` |
| TRA | 追踪 AOGM 归一化 | `AOGM = NS + 10·FN + FP + 1.5·ED + EA + EC` 加权和 |
| 附加 | 分裂/死亡事件 P/R、ID-switch 数、轨迹碎片数、每帧耗时/内存 | 用于误差归因与可视化 |

自检（关键）：把 `_GT/TRA` 直接作为提交结果喂给评测器，**SEG 必须 = 1.0、TRA/DET ≈ 1.0**；不满足说明管线有 bug，不允许进入后续阶段。

## 3. 留痕与实验管理规范（"每步留痕"落地方式）

### 3.1 目录结构

```
CellTracker/
├─ docs/                      计划、周报、决策记录 (ADR)
├─ data/                      # 不入库；由 download_data.sh 生成
│  ├─ raw/Fluo-N2DL-HeLa/
│  └─ interim/                # dataset.h5
├─ src/celltracker/
│  ├─ data/       解析/格式转换/退化注入
│  ├─ detect/     从 GT 或 nnU-Net mask 提取检测
│  ├─ cost/       C_feat、帧内图、FGW 结构项
│  ├─ ot/         Sinkhorn、非平衡 OT、多尺度正则
│  ├─ track/      轨迹重构、事件判定、tracklet 二层 OT
│  ├─ graph/      时间展开图构建
│  ├─ gnn/        模型、训练、推理
│  ├─ eval/       官方评测封装 + 附加指标
│  └─ viz/        全部绘图函数
├─ configs/                   yaml，每个实验一个文件
├─ experiments/               # 实验记录（入库，结果只增不改）
│  ├─ INDEX.md                # 总表：ID/日期/配置/git commit/指标/结论
│  └─ E2.3_sinkhorn_unbalanced/
│     ├─ config.yaml  command.sh  git_commit.txt  env.txt
│     ├─ metrics.json  per_sequence.csv
│     ├─ logs/  artifacts/(提交包、npz)  figures/(png+pdf)
│     └─ notes.md              # 假设→观察→结论→下一步
├─ figures/                   跨实验汇总图（论文用）
├─ tests/                     单测：OT 求解、指标封装、格式转换
└─ environment.yml  requirements.txt  README.md
```

### 3.2 每个实验必须产出的"留痕清单"

1. `config.yaml`（完整超参，含随机种子）
2. `command.sh`（可复现命令行）
3. `env.txt`（`pip freeze` + 平台 + 是否有 GPU）
4. `git_commit.txt`（实验时的 commit hash + dirty 标记）
5. `metrics.json` + `per_sequence.csv`（分序列、分指标的原始数字）
6. `logs/`（stdout/stderr）
7. `figures/`（至少 1 张主结果图，png + pdf）
8. `notes.md`（结论与下一步判断）
9. `experiments/INDEX.md` 追加一行（不修改历史行）

### 3.3 提交规范

- 粒度：**每完成一个可验证的小节（P0.1、P2.2 …）= 1 次提交**；提交信息格式 `[P2.2] 非平衡 OT 求解器 + E2.2 实验记录`。
- 每个 Phase 结束打 tag：`phase0-done`、`phase1-done` …
- 数据与模型权重不入库（`.gitignore`），只入库脚本、配置、指标与图表；大文件走云服务器/网盘并记录校验和。
- 结果不可覆盖：实验目录一旦生成，只允许新增修正实验（`E2.3-fix1`），原记录保留。

### Phase 2 — 相邻帧最优传输（Day 3–4；小规模本地，全量云）

| 任务 | 内容 |
| --- | --- |
| P2.1 | Sinkhorn 求解器；与线性规划（scipy/POT）在小规模上逐点对齐验证（数值单测） |
| P2.2 | `C_feat`：3D 位置²+尺寸归一化²+运动先验 α′；`R_max` 稀疏化与候选集裁剪 |
| P2.3 | 非平衡 OT：KL 松弛 (τ_t, τ_{t+1}) 与逐细胞 mass 权重（含增长因子 g_t） |
| P2.4 | FGW 结构项 η：3D 帧内 kNN 图 + 局部化/低秩近似，控制 O(n²n²) 复杂度 |
| P2.5 | 消融：η、ε、τ、α/β/α′、k(kNN)、`R_max`；平衡 vs 非平衡 |
| P2.6 | 轨迹重构：`argmax Γ` + θ_Γ/θ_C 阈值 + η_death/η_birth + 二分裂判定 |

**DoD**：OT 方案在 Fluo-N3DH-CE 上 TRA/DET 超过 Phase 1 最优基线；给出 η–ε 二维热图与分裂事件 P/R。
**云服务器**：本机先用 HeLa 代理 + 3D 子采样调参；**3D 全量重跑用云**。

### Phase 3 — 长程一致性与 tracklet 二层 OT（Day 5–6）

| 任务 | 内容 |
| --- | --- |
| P3.1 | 跳帧直接 OT `Γ^{t,t+k}_direct`（粗网格/子采样近似），k∈{2,3,5} |
| P3.2 | 多尺度时间正则 `R_temp^(k)`：复合耦合 vs 直接耦合的 Frobenius 差；交替优化（先独立求解再全局微调） |
| P3.3 | 运动先验闭环：由已建轨迹估计速度 → 反馈到 `C_feat` |
| P3.4 | 分层 tracklet OT：短窗高置信 tracklet → 超级节点 → 二层 OT 串联（遮挡/分割空洞恢复） |
| P3.5 | 消融与长程诊断：随帧距的漂移曲线、遮挡恢复成功率 |

**DoD**：长程模块使长轨迹（>30 帧）断裂率显著下降；给出"随时间累积误差"曲线。
**云服务器**：3D 全量多尺度重跑用云（可并行多个 k 值）。

### Phase 4 — 时间展开图 + GNN 残差校正（Day 7–9；本地调通 + **云 GPU 训练**）

| 任务 | 内容 |
| --- | --- |
| P4.1 | 图构建：节点特征 `h⁰=[x,s,f, t̃]`，跨帧候选边（θ_Γ、θ_C 筛选），帧内 kNN 边，边特征 `e⁰=[C,Γ,位移,尺寸对,Δt]` |
| P4.2 | 监督标签：由 `man_track.txt` 血缘生成边级 0/1（含正负样本不均衡处理：加权 BCE / focal） |
| P4.3 | 模型：边-节点交替消息传递 L 层 + 边分类头 + `L_OT-reg = Σ ŷ_e·C_e` |
| P4.4 | 训练/推理：CPU 小图调试 → 云 GPU 全量；推理后接轨迹重构 |
| P4.5 | 消融：层数、LOT-reg 有无、候选边阈值、跨帧桥接边（(i,t-1)→(k,t+1)）是否启用 |
| P4.6 | 误差归因四象限：FP 抑制率、FN 桥接成功率、过分割代表选择、欠分割不确定段标记 |

**DoD**：GNN 相对纯 OT 在 TRA 上有稳定提升（配对 t 检验/多序列一致）；四类分割误差的归因图完成。
**云服务器**：**必须**（训练阶段开机，结束即关机）。

## 8. 风险与应对

| 风险 | 应对 |
| --- | --- |
| CTC 数据无法下载（网络受限） | 需要你批准联网下载；备选：你手动放到 `data/raw/` |
| FGW 四重和复杂度过高 | 局部邻域截断 + 低秩/块近似；先小规模验证再全量 |
| 非平衡 OT + FGW 求解不稳 | 先固定 τ 大值退化为平衡 OT 调通，再逐步放松 |
| GNN 提升不显著 | 如实报告；退化为"OT + 规则后处理"，把精力放鲁棒性分析 |
| nnU-Net 训练成本 | 只用 2D 主数据集全量，3D 用子序列；云上按 epoch 存 checkpoint 可中断 |
| 结果不可复现 | 固定种子、冻结 config、`env.txt`、结果只增不改 |
