**三个最需要注意的点**：

1. **式(9) 的 FGW 结构项用的是 `D²`（距离平方），不是论文式(6) 定义的边权 `W`**；
   `W` 在全仓库是**死代码**（所有调用点都写 `D, _ = gaussian_knn_graph(...)`）。
   这意味着"FGW 在 CE 上无收益"的结论只适用于**我们的这个变体**，不能直接推广到论文形式。
2. **式(25) 的 `f`（外观特征）没有接 nnU-Net encoder**，用的是手工强度统计（均值/方差）→
   论文式(25) 的节点特征有一维语义完全不同。
3. **§1.6 的 `η_death`/`η_birth` 阈值、分裂的"体积守恒"判据、§2.0.1 的跨帧桥接边与
   入/出度建模**——论文明确写了，代码里都不存在（其中体积守恒有实测依据可豁免，其余三项需要补）。

> **对既有文档的一处更正**：此前 `docs/论文对齐核对.md` 称"式(25) 的 `intensity_std` 那一维恒为 0"。
> 实测不成立——GT h5 与预测 h5 的 `intensity_mean/std` 都是真实非零值
> （seq01 t=0：GT 131.5/42.6；预测 82.6/39.9）。该维不是死特征，**真正缺的是 `f`（encoder 特征）**。

  `η_death`/`η_birth`、体积守恒、桥接边），**零命中**才判定为缺口；
- 已证伪既有文档的一条结论（`intensity_std` 恒为 0），并给出实测数值；
- 本文所有代码位置均可通过 `grep -n` 直接复核。
