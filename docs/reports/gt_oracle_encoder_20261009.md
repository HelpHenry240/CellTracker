# GT marker Oracle 与冻结 nnU-Net encoder 验证

本轮在 GT 检测输入上重新提取 nnU-Net encoder 特征并独立训练 GNN，
不加入手工特征对照，也不重训分割网络。目的为测新版 pipeline 在排除检测误差后的表现。

## 协议

GT Oracle 指官方 TRA marker 的位置、身份和标记掩码，不是全细胞的 GT 分割。
两序列共385帧（195/190），包含23802/22418个检测；原 H5 逐帧与官方标记像素校验。
encoder来自既有冻结nnU-Net的stage2，在GT marker质心从原图采样128维特征。
实例身份只用于侧车对齐和训练边标签，不作为GNN输入的身份编码。

只在seq01标定候选/生死阈值及训练；种子20261008、20261009，每次60轮；
同一权重分别评测两序列，另重复seed20261008的完整seq02推理和官方评测。
GT marker没有真实细胞体积，沿用决策0001：均匀质量、不做体积守恒筛选。
保留孤立实例；CTC导出使用已有split策略，不补画GT之外的检测像素。
其余FGW、运动、多尺度、二层tracklet、候选筛选和GNN按现有全模块配置执行。
GT输入门限采用6.4µm：seq01真实位移p99.9=3.89048µm、最大5.30224µm，已覆盖。
λ_OT候选0.001；开始训练前核验完整上游及部署图的真实C分布和候选损失。

## 验收与结果

正式指标待本轮后台任务结束后追加。权威结果为官方DET/TRA及AOGM六项分解；
SEG在marker上不作科学解释。噪声重复与两个训练种子的全距分别记录，
差异小于0.001不作有效提升声明。

## 结论边界

没有同版本、同来源的手工特征重训对照，不能从本轮断言encoder带来提升或下降。
历史GT marker数值来自另一套实现/参数，保留作背景，不当作encoder消融基准。
GNN的seq02是跨序列测试，但既有nnU-Net训练包含部分seq02帧，不宣称端到端盲测泛化。
原始检测、nnU-Net权重、已有预测实例实验、完整GNN断点均保留。
