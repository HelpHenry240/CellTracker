## 二、三个隐性 bug（本阶段最大的收获）

这三处都不是"写错一个公式"，而是**不报错的错误**：程序照常跑完、指标照常输出，
只是结论全错。它们的共同特征是"指标合理、结论可疑"，只有做归因实验才会现形。

| # | bug | 症状 | 怎么发现的 | 影响 | 修复证据 |
| --- | --- | --- | --- | --- | --- |
| 1 | **标定配置 ≠ 部署配置**：`predict_to_h5` 用类默认 `h_frac=0.35`，但没把该参数暴露/写入 attrs；标定脚本默认 `h_frac=0.0` | h5 attrs 记着 `min_distance=6`（`h_frac>0` 时该参数**根本不生效**） | 评估 Distance Head 方案时复核后处理，发现"同参数复算实例数差 2 倍" | 标定曲线与部署配置不是同一语义，"最优参数"结论无效 | 修：`--h-frac` + attrs 记录 + 回归测试 |
| 2 | **EDT 未按物理间距计算**：`distance_transform_edt(binary)` 缺 `sampling` | 密集帧实例数只有标记数的 0.41；末端帧 88% 前景塌在一个连通域 | 顺着文档的"各向异性"提醒复核代码；CE 间距 (z,y,x)=(1.0,0.09,0.09) µm，z 粗 11 倍 | 距离图/h-maxima 峰/分水岭边界全部失真 → **人为的严重欠分割** | 修后：实例/标记 **0.41→1.007**，天花板 U0 0.407→**0.905**、U3 0.221→**0.723** |
| 3 | **分裂标签污染**：标签规则 `gt_parent.get(gl_d,0) == gl_s`，预测 h5 无 `tracks` 表 → `gt_parent` 为空 → 源检测是假阳性（`gl_s=0`）时退化成 `0==0` **成立** | 候选集中"分裂"标签边 **5866** 条，真实只有 **453** 条 | 误差漏斗出现 1294% 的异常比例，顺藤摸瓜查标签生成 | 分裂头在垃圾标签上训练；假阳性↔假阳性边被标成"移动" | 修后：分裂标签 5866→**378**，分裂事件 S3 2.2%→**21.1%**，本地分裂精确率 0.011→**0.489** |

**直接后果**：C4a 曾经得出"在真实检测上 GNN 不如匈牙利基线""分裂头学不会"的结论，
现已确认建立在这两个 bug 之上，相应记录均已追加更正说明
（`experiments/C4_pred_train/notes.md`、`experiments/C4_local_check/notes.md`）。

## 四、Oracle 上界实验怎么做的

**问题**：AOGM 分解显示前端相关约占 70%，但"前端还能拿回多少分"从未量化。

**做法**：保留 nnU-Net 掩码不变，只把"哪个体素属于哪个实例"换成正确答案——
用 `_GT/TRA` 标记作 marker-controlled watershed 的种子（`split_instances(seeds=...)`），
跳过 h-maxima 找峰；其余链路（OT → 式(26) 候选 → GNN → 重建 → 官方评测）完全不变。

**三个刻意的约束**（避免 oracle 偷偷作弊更多）：种子落在掩码外 → 不产生实例；
掩码内无种子的连通域 → 丢弃；标记直接作种子、**不膨胀**（标记与核体积约 1:23，
膨胀会让边界虚高）。

**结果**：TRA 0.9057 → **0.9848**；漏斗里 move 边 S3 留存 83.1% → **98.2%**，
分裂事件 S3 21.1% → **75.8%**，GNN 分裂 F1 0.215 → 0.534。

**用途**：它是**决策实验**——上限高（+0.079，是追踪侧任何改动 10 倍量级）说明
前端实例化值得投入，追踪侧不再继续调参；同时它给 Distance/Boundary Head 一个明确的
收益区间（起点 0.9057、上限 0.9848）。

⚠️ oracle 用真值当种子 = 作弊，只是上界；且它的优势还包含"实例与真值 1:1，
因此 GNN 训练标签也干净"，真实方法拿不到这部分。

## 五、方法论教训（已写入 AGENTS.md 或需补入）

1. **"跑得通 + 指标合理"不等于正确**：三个 bug 全是隐性错误，只有**误差归属实验**
   （检测层天花板 U0–U3、误差漏斗、oracle 上界）能把它们逼出来。
2. **凡是从"体素单位"推导的尺度参数都要按物理间距标定**（间距、平滑核、
   距离图、乃至 OT 代价里的 `r_max`）。
3. **判据必须与被评估的失败模式匹配**：实例拆分的 F1 在欠分割时**单调升高**，
   等于奖励错误方向；正确判据是"实例/标记比 + 标记独立性（exclusive）"。
4. **结论必须双序列 + 官方指标 + 噪声地板**：本阶段官方差值 +0.00084 只有噪声地板
   （0.0007）的 1.2 倍，因此 top-k 扩容记为"方向一致、幅度不足"，不改默认参数。
5. **留痕口径要与生效配置一致**：报告、attrs、命令行默认值三者不一致是事故源头。

## 七、当前可写进论文的结论

1. **严格按论文口径搭链路本身带来实质提升**：早期偏离期实现 seq02 输给基线，
   改口径后双序列稳定胜出（0.996513 / 0.996369 vs 基线 0.995594 / 0.995052）。
2. **学习型决策是必需项**：GT 检测上 −GNN = −0.0034（4.9× 噪声地板）。
3. **论文的三个扩展在 CE 上无正收益**（FGW / 非平衡 / 运动先验），与先验判别力
   AUC 测量方向一致。
4. **端到端瓶颈的定量归属**：在真实 nnU-Net 前端下，剩余损失的约 70% 来自
   "实例归属"（NS + FP + 约一半 EA），前端实例化的收益上限 **+0.079 TRA**，
   而追踪侧可挖空间 ≤ 0.012。
5. **方法的鲁棒性边界**：检测完美时追踪器只丢 2% 的真实边（EA 505）；
   检测退化为"实例数正确但归属不稳"时，EA 升到 7602 —— 说明瓶颈不在追踪算法本身，
   而在其输入的实例质量。
